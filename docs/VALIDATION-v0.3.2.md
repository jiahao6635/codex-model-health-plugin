# v0.3.2 CPS v3.29.3 兼容性验收

日期：2026-10-19。保留本地 v0.3.1 的邮箱展示和页面内串行/并行批量检测，适配 CPS v3.29.3。此记录覆盖发布前验证；未更新线上服务，未调用真实模型。

## 兼容性变更

- 插件、后端与前端版本统一为 0.3.2；宿主范围为 `>=3.29.3, <4.0.0`。
- SDK 与官方打包 CLI 均固定到 CPS v3.29.3 的提交 `16d8a3f87309d9346a5f204673390fe20478b40e`；Rust 为 1.99.1。
- 使用 RPC v4 和 `management` v2；安装包夹具按新协议将配置、参数、结果及入口请求快照写入独立载荷前缀。
- Rust 协议夹具断言 RPC v4 握手与管理能力 v2，并覆盖有入口请求快照的管理调用和无快照的并行调用。
- 插件 ID `local.model-health`、`runs` / `automation` 状态声明及 schema 均与 v0.3.1 相同；不恢复后台调度或自动隔离。
- Meow / ModelTrace 的算法、题库、基线及内嵌 Python 引擎没有改动；Linux 包复用此前构建的相同引擎。

## 验证结果

- Rust 1.99.1 本地：11 个单测、21 个协议测试全部通过；fmt / Clippy（all-targets，warnings 为错误）通过。
- Rust 1.99.1 / Linux x86_64：`bundled-engine` 的同一组 32 项测试通过，发行二进制构建通过。
- Python：16 项检测引擎测试通过。
- 前端：10 项测试、类型检查与生产构建通过。本轮未改动 UI，未重跑浏览器截图验收。
- 官方 CLI 安装包通过独立 Python 宿主夹具验收：RPC v4 握手、management v2 清单、载荷前缀、Meow 36/36、ModelTrace 3/3、冻结账号与 Key、暂停/续测、历史读取、更新缓存和 HTTP 400 错误响应均通过。
- 安装包摘要、非 root、空环境、只读根目录与 `/tmp:noexec` 验收通过；所有推理为模拟回调，真实模型调用为零。
